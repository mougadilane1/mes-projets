# Mes projets

## Classifieur de texte (Naive Bayes)

Un petit programme d'intelligence artificielle écrit en Python pur, sans aucune bibliothèque externe.

Il apprend à reconnaître si une phrase est **positive** ou **négative** en comptant les mots vus dans des exemples.

### Lancer le programme

    python classifieur.py

Écris une phrase et le programme donne sa prédiction. Tape `q` pour quitter.
